# כסף 💸

אפליקציית אנדרואיד אישית למעקב אחרי הוצאות והכנסות.

- **עיגול יתרה גדול** במסך הראשי: כמה נשאר מההכנסות של החודש.
- **קליטה אוטומטית מ-Google Wallet**: כל תשלום בטלפון נרשם לבד, דרך ההתראה של Wallet.
- **סיווג לקטגוריות**: אוטומטי לפי שם העסק, והאפליקציה לומדת כשמתקנים לה.
- **תזכורת יומית** וסיכום הוצאות.
- **עדכונים מתוך האפליקציה**: בלי להוריד קבצים ידנית.

## התקנה ראשונה
1. בטלפון, פתח את דף ה-[Releases](https://github.com/pooopic/kesef/releases/latest) והורד את קובץ ה-APK.
2. אשר "התקנה ממקור לא ידוע" והתקן.
3. באפליקציה: הגדרות → "פתח גישה להתראות" → הפעל את "כסף".
   אם האפשרות אפורה: הגדרות הטלפון → אפליקציות → כסף → ⋮ → "התר הגדרות מוגבלות".

מכאן והלאה העדכונים מגיעים מתוך האפליקציה.

## איך יוצאת גרסה חדשה
כל push ל-`main` מריץ את GitHub Actions: בדיקות → בנייה → Release חדש.
הודעת ה-commit היא "מה חדש" שמופיע באפליקציה.
