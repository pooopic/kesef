# פורמט ייבוא נתונים לאפליקציית "כסף"

האפליקציה מייבאת קובץ **CSV** אחד בפורמט קבוע. כל מקור נתונים (כרטיס אשראי, חשבון בנק, מזומן)
צריך לעבור המרה לפורמט הזה לפני הייבוא. אפשר לייבא כמה קבצים, אחד אחרי השני.

## איך שומרים מאקסל
קובץ ← שמירה בשם ← סוג קובץ: **CSV UTF-8 (מופרד בפסיקים)**.
(גם "CSV" רגיל עובד, אבל UTF-8 בטוח יותר לעברית.)

## העמודות
השורה הראשונה היא שורת כותרות, בדיוק בשמות האלה. הסדר לא משנה, ועמודות נוספות פשוט לא נקראות.

| עמודה | חובה | מה כותבים | דוגמה |
|---|---|---|---|
| תאריך | ✔ | יום/חודש/שנה | `29/12/2025` |
| סכום | ✔ | בשקלים, בלי ₪. מספר חיובי. | `208.23` |
| קטגוריה | ✔ | שם הקטגוריה. אם אין כזו באפליקציה, היא תיווצר. | `סופר` |
| סוג | | `הוצאה` או `הכנסה`. ריק = הוצאה. | `הוצאה` |
| תיאור | | שם בית העסק / מקור ההכנסה | `CARREFOUR מזכרת בתיה` |
| אמצעי תשלום | | מאיפה יצא/נכנס הכסף | `ויזה 3447`, `בנק`, `מזומן` |
| הערה | | חופשי | `תשלום 2 מתוך 3` |

## כללים
- **זיכוי / החזר:** בהוצאה כותבים סכום **שלילי** (`-150`). הוא יירשם כהכנסה בקטגוריית "החזרים".
- **תשלומים (קרדיט):** שורה לכל חיוב חודשי בפועל, עם התאריך והסכום של אותו חיוב.
- **שורות עם סכום 0** מדולגות.
- **ייבוא חוזר של אותו קובץ לא יוצר כפילויות.** שורה זהה (תאריך + סכום + סוג + תיאור + אמצעי תשלום) נכנסת פעם אחת בלבד.
- **חשבון בנק:** אל תכלול את שורות החיוב החודשי של כרטיסי האשראי ("כאל", "מקס", "ישראכרט" וכו').
  ההוצאות האלה כבר נכנסות מהפירוט של הכרטיס, אחרת הן ייספרו פעמיים.

## קטגוריות קיימות באפליקציה
הוצאות: סופר, אוכל בחוץ, תחבורה ודלק, דיור, חשבונות, קניות, בריאות, בילויים, לימודים, מתנות, אחר
הכנסות: משכורת, מלגה, מתנה, החזרים, אחר

כדאי להשתמש בשמות האלה כשאפשר, כדי שגם תשלומים שנקלטים אוטומטית מ-Wallet יגיעו לאותן קטגוריות.

## דוגמה
ראו [`import-example.csv`](import-example.csv).

## המרה אוטומטית מפירוט כרטיס אשראי
`tools/convert_card_excel.py` ממיר את קובץ האקסל של פירוט הכרטיס (העמודות: חודש, כרטיס, בית עסק,
קטגוריה, תאריך עסקה, סכום העסקה, סוג העסקה, פירוט, תאריך החיוב, סכום החיוב) לפורמט הזה:
```
python tools/convert_card_excel.py "סיכום הוצאות 2026.xlsx"
```
